But the embedded COMcheck reports on BOTH sheets are for a DIFFERENT project entirely: Project Title "Bailey's Forest Event Center", site 18375 Barnhardt Road, Cornelius, NC 28036, owner Palillo Holdings LLC (Mooresville, NC), MWT job 23-030, report date 08/02/24. The printed COMcheck title text is exactly: "Bailey's Forest Event Center" (with apostrophe; the data filename also uses "Bailey's Forest Event Center" and "Baileys Forest Event Center" without apostrophe in the .cck filename).

CONSEQUENCE FOR THE BULB-ORDER REPORT: the fixture quantities on E800/E801 (141 interior / 20 exterior fixtures, IDs EM, L1, L2, R1, S1, S2, X1, X2, P1, R2, EXT) describe the ~7,026 ft2 Bailey's Forest Event Center convention building in Cornelius, NC — NOT the 115-key, 4-floor Home2 Suites in Eagle Pass. These counts must be flagged UNVERIFIED as a building-wide fixture count for H2SEP; they cannot be used for the Home2 bulb order.
